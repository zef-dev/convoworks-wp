Convo Chat
Will be used to parse input text into intent based result

You can embed this service as a chat widget on any WordPress page or post using the [convo_chat] shortcode. For this service, the basic usage is:

[convo_chat service_id="{{service.service_id}}"]

Optional attributes: title (default Chat), variant (default b), font_size (default 18px), default_width (default 520px).

Example: [convo_chat service_id="{{service.service_id}}" title="Support Chat" variant="b" font_size="16px" default_width="480px"]
