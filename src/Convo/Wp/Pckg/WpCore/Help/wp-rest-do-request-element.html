WP REST Do Request

Performs an internal WordPress REST API request and stores the result in a variable.

Parameters

  • HTTP Method (string):
    HTTP method for the request (e.g., GET, POST, PUT, DELETE). Default is GET.
  • REST Route (string):
    REST API route to call (e.g., /wp/v2/posts).
  • Query Parameters (array):
    Query parameters to pass to the request. Provide as key-value pairs.
  • Body Parameters (array):
    Body parameters to pass to the request (for POST, PUT, etc). Provide as key-value pairs.
  • Result variable name (string):
    Name of the variable to store the result in. Default is wp_rest_result.
  • On Success (components):
    Components to execute if the request is successful.
  • On Failure (components):
    Components to execute if the request fails.

Usage

The result of the REST request will be available in the variable specified by Result variable name.
Use Query Parameters for GET parameters and Body Parameters for POST/PUT parameters.

Example: To get posts, use HTTP Method: 'GET' and REST Route: '/wp/v2/posts'.
