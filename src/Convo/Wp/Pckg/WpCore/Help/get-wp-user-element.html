Init Current Auth User Element

Initiates the authentication process of an WordPress User and displays the data of the user.

When to use?

When you want to link WordPress User Accounts with an Alexa Skill.

How to use:

  1. Make sure you already have configured and propagated your service to Amazon Alexa with Account Linking enabled in Account Linking Mode 'Installation'.
  2. Enter variable name for the user in Name field Name under which to store the loaded user object in the context
  3. If you want to prompt account linking directly from the element, just check Prompt for linking. To initiate prompt account linking, You can also use the Prompt Account Linking element which is in convo-core package.
  4. After the account linking process was successfully finished, you'll be able to access the user data like in the following examples:
    • ${user.id}
    • ${user.name}
    • ${user.username}
    • ${user.email}
    • ${user.wpUser}

Fore more info on ${user.wp_user} please check out the WordPress Code Reference.
