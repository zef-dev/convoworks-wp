### Start Video Playback

Start video playback from a provided video URL.

### When to use

Use **Start Video Playback** when:

- You want to play video content on a device that supports video playback.
- You have a direct URL to the video file or stream.

### Properties

#### Video URL

URL of the video to play.

- Should be reachable and in a supported format for the target platform.

#### Title (optional)

Title displayed for the video (where supported).

#### Subtitle (optional)

Subtitle or secondary text for the video.

- If title or subtitle are not passed, no additional video info will be displayed.

### Tips

- Always ensure the URL is valid and accessible from the user’s device.
- Provide a meaningful title/subtitle where possible to improve the user experience.
