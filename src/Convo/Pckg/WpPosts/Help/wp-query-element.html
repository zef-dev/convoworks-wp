WP Query ELement

Gives access to the WP_Query object defined by WP Query context component.

Not in the loop

While you have access to the WP_Query object, you can access all its members and you can even loop over query.posts, note that in such case you are not in the loop and you can not use wp functions without arguments (as you can do inside e.g. WP Loop element).
If you would like to do a quick, but fully functional loop over resulting posts you can use "WP Loop Element" and place it inside "Has results" flow.

When to use?

This element allows you to quickly check if there are any results and based on that you can prepare the right user workflow. For example, you might define different responses or conversation steps if there are not results, if there are just one result and if there are multiple pages of results.
