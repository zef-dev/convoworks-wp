WP Query Context

Defines WP_Query to be used as the source for the other WP specific components. It maintains the pagination and post selection info during the session.

Arguments

All arguments are passed to the real WP_Query class except offset which is calculated dynamically. You can use expressions when defining arguments. The expressions are evaluated in the service scope so you can not use internal variables which are available inside e.g. Loop element.

Maintaining the pagination

As mentioned, this component keeps track of the current page during the navigation through results. If you want to rewind it to the begining, you can do it by providing expression which evaluates to true to Rewind navigation.
