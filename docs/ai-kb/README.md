## Convoworks AI Knowledge Base

This folder contains AI‑oriented documentation for Convoworks components and workflow patterns.

- `patterns/` – cross‑service recipes and “how to solve X” guides.
- `functions/` – per‑function / per‑tool reference cards.
- `services/` – optional per‑service docs (overview, flows, contexts), generated from a service JSON when needed.

Each markdown file starts with frontmatter that can be used to drive vector indexing and search. See `docs/ai-kb/index.jsonl` for the catalog.
