## Convoworks AI Knowledge Base

This folder contains AI‑oriented documentation generated from real Convoworks services and components.

- `services/` – per‑service docs (what a service does, its flows, contexts).
- `patterns/` – cross‑service recipes and “how to solve X” guides.
- `functions/` – per‑function / per‑tool reference cards.
- `platforms/` – integration overviews (FluentCRM, LearnDash, TablePress, etc.).

Each markdown file starts with frontmatter that can be used to drive vector indexing and search.
